# AI-Powered Route Navigation Guide

## Overview
Enhance the Route Planner page with AI-generated turn-by-turn navigation guidance, travel tips, and contextual information for each leg of the journey.

## Current State
- Route optimization shows distance and duration for each leg
- Google Maps integration for visual route display
- "Open in Google Maps" button for external navigation
- No in-app navigation guidance or travel tips

## Proposed Features

### 1. AI Route Guide Card (New Section)
**Location:** Below optimized route info, above save dialog

**Features:**
- **Travel Tips by AI**: Generate contextual travel advice based on route distance, time, and locations
- **Best Time to Travel**: Suggest optimal departure times based on traffic patterns
- **Weather Considerations**: Note about checking weather for long-distance routes
- **Fuel/Rest Stops**: AI suggests where to stop for fuel, food, or rest based on route length

**UI Components:**
```jsx
<Card className="border-primary/20 bg-gradient-to-br from-primary/5 to-emerald-50">
  <CardContent className="p-4">
    <div className="flex items-center gap-2 mb-3">
      <Sparkles className="h-5 w-5 text-primary" />
      <h3 className="font-semibold">AI Travel Guide</h3>
    </div>
    <div className="space-y-3 text-sm text-muted-foreground">
      {/* AI-generated content */}
    </div>
  </CardContent>
</Card>
```

### 2. Turn-by-Turn Navigation Preview
**Location:** Expandable accordion below each route leg

**Features:**
- Show first 2-3 key turns/directions for each leg
- Expandable to see full step-by-step directions
- Bengali/English toggle for directions
- Copy directions button

**Data Source:** Use existing `legs[].steps` from `/api/directions` response

**UI Components:**
```jsx
<Accordion type="single" collapsible className="w-full">
  {optimizedRoute.legs.map((leg, i) => (
    <AccordionItem value={`leg-${i}`} key={i}>
      <AccordionTrigger>
        Leg {i + 1}: {leg.startAddress} → {leg.endAddress}
      </AccordionTrigger>
      <AccordionContent>
        <ol className="space-y-2 text-sm">
          {leg.steps.map((step, j) => (
            <li key={j} className="flex gap-2">
              <span className="text-primary font-bold">{j + 1}.</span>
              <span dangerouslySetInnerHTML={{ __html: step.instruction }} />
            </li>
          ))}
        </ol>
      </AccordionContent>
    </AccordionItem>
  ))}
</Accordion>
```

### 3. AI-Powered Route Description
**New API Endpoint:** `/api/route-guide`

**Purpose:** Generate contextual travel guide for the entire route

**Prompt Template:**
```
You are a travel guide for Bangladesh. Create a helpful route guide for a road trip.

Route Details:
- Places: [place1, place2, place3, ...]
- Total Distance: X km
- Total Duration: Y minutes
- Districts: [district1, district2, ...]

Provide in {language}:
1. Route overview (2 sentences)
2. Best time to start this journey
3. Recommended stops for food/fuel
4. 3 travel tips specific to this route
5. Any seasonal considerations (monsoon, winter, etc.)

Format as JSON with sections: overview, bestTime, stops, tips, seasonal
```

**Response Format:**
```json
{
  "overview": "This X km journey takes you through...",
  "bestTime": "Start early morning (6-7 AM) to avoid traffic...",
  "stops": ["Fuel: Place A at 50km", "Food: Restaurant B at 75km"],
  "tips": ["Keep cash for toll booths", "Network coverage may be weak in section C"],
  "seasonal": "Avoid during monsoon (June-August) due to flooding risks"
}
```

### 5. Route Difficulty Indicator (New)
**Logic:**
```javascript
const getRouteDifficulty = (distance, duration, legCount) => {
  const hours = duration / 60;
  if (hours > 6 || distance > 300) return { level: 'challenging', color: 'red' };
  if (hours > 3 || distance > 150) return { level: 'moderate', color: 'yellow' };
  return { level: 'easy', color: 'green' };
};
```

**UI:**
```jsx
<div className="flex items-center gap-2">
  <Badge variant={difficulty.color}>{difficulty.level}</Badge>
  <span className="text-xs text-muted-foreground">
    {difficulty.level === 'challenging' ? 'Consider breaking into multiple days' : 'Suitable for day trip'}
  </span>
</div>
```

## User Flow

1. User selects 3+ places on Discover page
2. Navigates to Route page
3. Clicks "Optimize Route"
4. Route is calculated, distance/duration shown
5. **NEW:** AI Route Guide automatically generates
6. User sees:
   - Total distance & duration
   - Route difficulty badge
   - AI travel tips card (expandable)
   - Turn-by-turn directions (accordion)
7. User can:
   - Read AI tips before journey
   - Expand each leg for detailed directions
   - Save route with AI guide included
   - Share route guide with friends

## Success Metrics
- Users can understand their route without opening Google Maps
- AI tips provide actionable travel advice
- Bengali speakers get native language guidance
- Reduced dependency on external navigation apps
