# Tour Guide App - Rebranding & Enhancement Plan

## Overview
Rebrand the application from "KGC Tour Guide" to "Tour Guide" throughout the entire project, improve PWA loading experience, and standardize content.

## Goals
1. Rename app from "KGC Tour Guide" → "Tour Guide"
2. Remove all KGC references (except internal technical IDs where safe)
3. Enhance PWA loading experience with animated spinner
4. Standardize content and improve consistency
5. Update all branding, metadata, and user-facing text

### 2. Internal Storage Keys (Safe to Rename)

#### Files to Update:
- `src/store/useTravelStore.js`
  - storage key: `tour-guide-storage` (from `kgc-travel-storage`)

- `src/app/route/page.js`
  - localStorage key: `tour-guide-saved-routes` (from `kgc-saved-routes`)

- `src/app/saved/page.js`
  - localStorage key: `tour-guide-saved-routes`

- `public/sw.js`
  - CACHE_NAME: `tour-guide-v2` (from `kgc-v2`)

**Note:** Changing storage keys will reset user data. Consider migration strategy or keep existing keys for backward compatibility.

**Decision:** Keep storage keys as-is for backward compatibility. Only rename user-facing branding.

### 3. Technical IDs (Keep As-Is)

The following should NOT be changed as they are internal technical identifiers:
- `public/sw.js` - CACHE_NAME: Keep `kgc-v2` for backward compatibility
- `src/components/map/GoogleRouteMap.jsx` - mapId: `kgc-route-map` (Google Maps API reference)
- `src/components/map/GoogleDiscoverMap.jsx` - mapId: `kgc-discover-map`
- `src/components/map/GoogleDiscoverMap.jsx` - window callbacks: `__kgc_onAdd`, `__kgc_onDetails`
- `src/components/map/LeafletDiscoverMap.jsx` - window callbacks: `__kgc_onSelect`
- `src/app/discover/page.js` - User-Agent: `KGC/1.0` (OSM API identifier)
- `src/lib/map-providers/index.js` - User-Agent: `KGC-Tour-Guide/2.0`

**Reason:** These are internal technical identifiers that users never see. Changing them provides no user benefit and could break existing functionality.
